# Contributing

Contributions are welcome.

## Ways to contribute

- Report bugs
- Suggest new features
- Submit pull requests
- Create new story templates
- Translate the interface into new languages
- Improve the documentation

## Reporting issues

When reporting a bug, include:

- What you expected to happen
- What actually happened
- Steps to reproduce the problem
- Browser and operating system
- A minimal `story.json` or repository link when relevant

Open an issue on [GitHub](https://github.com/Z4RD0Z/librogame-engine/issues).

## Pull requests

- Keep changes focused.
- Match the existing code style.
- Update the documentation when behavior changes.
- Test the game locally with `python -m http.server`.

## Story templates

If you create a reusable story template, consider sharing it as a separate repository or as an example in the project.
